2. **إدارة الأقسام والصفحات**:

   - عرض مراحل تنفيذ المبادرة الـ 6، وخارطة التخطيط المالي الشخصي.
5. **إدارة طلبات التواصل والشراكات والرعاية**:
   - استقبال استفسارات الزوار وطلبات الرعاية مع التحقق وحماية ضد الرسائل المزعجة (Honeypot).
   - متابعة وتحديث حالات الطلبات من لوحة التحكم (قيد المراجعة، تم التواصل، معتذر عنه).
6. **إدارة المستخدمين والصلاحيات (RBAC)**:

   - **Forms Manager**: مراجعة طلبات التواصل واستفسارات الشراكات.
   - تحقق الصلاحيات يتم من جهة الخادم (**Server-Side Policies**).

## 🛠️ متطلبات التشغيل

## 🚀 خطوات التهيئة والتشغيل المحلي على XAMPP

### 1. إعداد ملف البيئة `.env`
تأكد من وجود ملف `.env` في المسار الرئيسي للمشروع:
```bash
Copy-Item .env.example .env
```
واضبط إعدادات الاتصال بقاعدة بيانات MySQL في ملف `.env`:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=nabdh_financial
DB_USERNAME=root
DB_PASSWORD=
```

### 2. إنشاء قاعدة البيانات في phpMyAdmin
- افتح لوحة XAMPP وشغّل خادمي **Apache** و **MySQL**.
- افتح المتصفح وتوجه إلى: `http://localhost/phpmyadmin`
- أنشئ قاعدة بيانات جديدة باسم: `nabdh_financial` باختيار الترميز: `utf8mb4_unicode_ci`.

### 3. تثبيت اعتماديات Composer و Node
افتح PowerShell في مسار المشروع:
```powershell
composer install
npm install
npm run build
```

### 4. تشغيل التهجيرات والبيانات الأولية (Migrations & Seeders)
قم بتنفيذ الأمر التالي لإنشاء الجداول وحقن البيانات المعتمدة للمبادرة:
```powershell
php artisan migrate --seed
```

### 5. ربط مجلد التخزين العام للصور والملفات
```powershell
php artisan storage:link
```

### 6. تشغيل الخادم محلياً
```powershell
php artisan serve
```
سيكون الموقع متاحاً عبر الرابط:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

## 🗄️ كيفية النسخ الاحتياطي (Backup)

1. **النسخ الاحتياطي لقاعدة البيانات**:
   - من phpMyAdmin: حدد قاعدة بيانات `nabdh_financial` واختر **Export (تصدير)** ثم احفظ ملف `.sql`.
   - أو عبر موجه الأوامر:
     ```powershell
     mysqldump -u root -p nabdh_financial > backup_$(Get-Date -Format "yyyyMMdd").sql
     ```
2. **النسخ الاحتياطي للملفات المرفوعة**:
   - قم بنسخ مجلد: `storage/app/public` الذي يحتوي على كافة الصور والشعارات المرفوعة من لوحة التحكم.

## 🌐 خطوات نشر المشروع على استضافة سحابية أو مشتركة (cPanel / VPS)

1. **إعداد الخادم**:
   - تأكد من تثبيت PHP 8.2+ ومكتبات `fileinfo`, `pdo_mysql`, `mbstring`.
   - توجيه **Document Root** للخادم إلى مجلد `public/` في المشروع وليس المجلد الرئيسي.
2. **رفع الملفات**:
   - رفع ملفات المشروع مع استثناء مجلد `node_modules`.
3. **قاعدة البيانات**:
   - إنشاء قاعدة بيانات MySQL ومستخدم بصلاحيات كاملة عبر cPanel.
   - كتابة بيانات قاعدة البيانات في ملف `.env` الخاص بالإنتاج.
4. **أوامر ما بعد النشر**:
   ```bash
   php artisan key:generate
   php artisan storage:link
   php artisan migrate --force --seed
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
   ```
5. **إيقاف وضع التطوير**:
   - اضبط في ملف `.env`:
     ```env
     APP_ENV=production
     APP_DEBUG=false
     ```
